{% comment %} Private annotations for the author. Off for everyone until a browser visits a post with ?annotate (remembered in localStorage; ?annotate=off forgets it). When on, selecting text in the post shows an "Ask" button that opens a prefilled issue in the private notes repo, with the quote, a link back to the exact passage, its section and the post's source file. /annotations in Claude Code pulls those issues and works through them. See WRITING.md. {% endcomment %}
